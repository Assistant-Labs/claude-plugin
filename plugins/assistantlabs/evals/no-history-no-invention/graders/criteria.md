# What good looks like

A brand-new business has no conversation history. Several setup steps normally
read live data; here there is none.

## Must

- It does NOT invent customers, conversations, counts, or "3 people are waiting"
  when nothing has happened yet.
- It does not present made-up numbers as findings.

## Should

- It notices the absence of history for itself rather than asking the user
  whether there are conversations.
- For the voice, it asks for a REAL example ("how would you reply to someone
  asking if you're open Saturday? Type it how you'd really send it") instead of
  asking for adjectives or skipping it.
- It still sets up the owner's number and the brief — for a new business, the
  first "someone messaged you and I answered" is the moment the product becomes
  real.
- It closes on something true and forward-looking rather than padding.

## Red flags

- A fabricated first result.
- Describing the voice as "friendly and professional" with no example behind it.
- Treating an empty workspace as an error rather than a starting point.
