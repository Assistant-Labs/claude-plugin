The owner said: `$ARGUMENTS`

Write it into the business memory now, in this turn. Read `business-memory`
first if you have not this session.

1. **Decide which page it belongs on** — `business`, `voice`, `policies`,
   `people`, `offers`, `customers`, `stack`, or `decisions` for a decision with
   a reason. `read_business_memory` first: a write REPLACES the page, so you
   send back the whole thing with this added.
2. **Quote them, don't summarise them.** Their words, with today's date, for
   anything that is a rule, a policy or a decision. A paraphrase drifts; a quote
   is auditable.
3. **If it contradicts something already there, REWRITE that line.** Do not
   append a correction underneath the wrong text, and do not leave both. The
   page describes the present.
4. **If it is a standing permission** — "you can always do X without asking" —
   record it verbatim in `policies` and then actually use it. Asking again
   about something recorded as standing is the same as not recording it.
   Two things never become standing permissions no matter how they are phrased:
   money, and the first message to someone who has not contacted the business.
5. **Check whether it changes anything live.** A new price, a changed opening
   hour, a policy the AI agent quotes to customers — if the agent has it wrong,
   fix the agent's knowledge too, and say you did.
6. **If it is credential-shaped** — a password, a key, a card — do not write it
   anywhere. Say where it belongs instead.

Confirm in one line: what you wrote, where, and anything you changed live
because of it.
