Produce the weekly review for `$ARGUMENTS` (default: the last seven days).

Read `weekly-report` first — it holds the one number, the sections, and the
sources. Then `reporting-to-the-owner` for the voice.

**Ask them first** — at most three questions, one at a time, with choices they
can tap. The first is always what happened this week that the system would not
know about: calls, visits, anything agreed face to face. Wait for each answer
before the next, and never ask what the data already answers.

**Then, before writing anything**, read the owner's own messages in each conversation,
the notes on each contact, and the activity timeline. The agent's view is half
the relationship, and a weekly report built from the agent's half alone gets
customers and leads confidently wrong. If something is missing from all of them,
ask the owner — one question usually changes the whole report.

**List every open lead, not a recent window.** The oldest neglected lead is the
most expensive one to lose.

Finish with next week's proposed work — builds that stop a problem recurring,
not this week's tidying — each one enough for somebody else to pick up cold.
They approve by replying with the numbers.

It is a document. Hand it over, and say one line in chat.
