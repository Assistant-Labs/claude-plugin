description: Who hasn't been answered — and the drafts to fix it
---

Find every customer waiting on a reply and prepare the answers. Read
`customer-conversations` first.

1. **Find them.** `conversation_stats` → the no-reply list. Then check the
   recent conversations directly for anything it missed.
2. **Strip the machines.** Away-messages, auto-replies, delivery receipts. A
   thread where only robots spoke is not someone waiting.
3. **Sort by how long they have waited**, longest first.
4. **For each one, read the actual thread** — enough to know what they want, not
   just the last line. Note any image the agent could not read: that is an
   unanswered question, not a completed exchange.
5. **Check the board** for a task and for anything that happened off-channel. A
   note beats the thread.
6. **File anyone with no task row.** That is something you missed.
7. **Draft every reply**, in the business's voice and the customer's language,
   plain sendable text.

Then hand them over: each customer, how long they have waited, what they want in
one line, and the finished reply. If the owner is here, ask about them one at a
time. If not, file each as `blocked-on-a-human` with the reply in the body.

Lead with the count and the oldest. If nobody is waiting, say that in one line —
it is good news and it takes one line.
