description: Where the money is — owed, at risk, and coming in
argument-hint: "[this month|last month|<question>]"
---

Answer the money question in `$ARGUMENTS`, or run the standing check if there is
none. Read `money-and-billing` first.

The standing check, in this order:

1. **Who owes money and for how long** — oldest first, with the amount.
2. **Failed or missing payments** in the last cycle.
3. **Work delivered with no invoice raised** — the commonest hole there is.
4. **Anything renewing or expiring in the next two weeks.**
5. **Quoted vs paid** on recent jobs.
6. **This period vs last**, against the target in the `offers` memory page.

Rules:

- **Say where each number came from**, on the same line. A money figure with no
  source is worse than no figure.
- **Flag anything partial or excluded** rather than rounding past it.
- **Never enter, store or repeat a card, bank detail or payment credential.** If
  one is sitting in a conversation, say it is there — do not copy it.
- **Prepare, never charge.** Invoices, reminders and reconciliations get built
  and shown. Nothing is sent, charged, refunded or discounted without a specific
  yes.

File a task for each real hole, with the number in the title. End with the
single largest thing at risk and what you'd do about it.
